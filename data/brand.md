# ブランドの定義

ドメインの決裁後に記入する。出品原稿、商品選定、モール外の販促はすべてこれに合わせる。

| 項目 | 内容 |
|---|---|
| ドメイン | （未決） |
| ブランド名 | （未決。商標の空きを J-PlatPat で確認してから決める） |
| ターゲット | 例：専門店の価格に割高感を持つ、中級者以上の愛好家 |
| 提供価値 | 例：専門店と同等の仕様を、選定と品質チェックを経て手の届く価格で |
| 原稿のトーン | 例：仕様と根拠で語る。煽る表現は使わない |
| 共通の訴求点 | 例：全数検品、仕様の明示、日本語でのサポート |
| 拡大先のドメイン | （未決） |

**注意：** MVPの段階では、商品そのもので他社と差をつけることは難しい（同じ工場の商品を他の出品者も仕入れられる）。ブランドの価値は、選定、品質チェック、原稿、サポートの質で作る（`docs/strategy.md`）。
