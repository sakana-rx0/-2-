# スーツのリユース・仕立て直し事業：可能性の分析（2026-10-31）

**問い：** 状態の良い中古スーツを安く集め、「仕立て直し」して良い生地のスーツを安く提供する仕組みを大規模に展開すれば、儲かるか。

**結論：**
- **「仕立て直し」（解体して裁断し直す）を軸にすると、儲からない。** スーツの価値の大半は生地ではなく「縫製の手間」と「体に合うこと」にあり、仕立て直しはその最も高い部分を、手作業で、1着ずつ、もう一度払う構造になっている。しかも、新品のパターンオーダーがすでに安い。
- **ただし「新品と中古の価格差」という着眼は正しい。** 価格差が生まれる最大の理由は「中古は自分の体に合うか分からない」こと。**直して合わせるのではなく、合うものを選んで、少しだけ直す**（採寸データでのマッチング＋軽微なお直し）に組み替えれば、粗利率50%前後の事業になりうる。
- **最適なモデル：「採寸済みの中古テーラードを、お直し込みで販売するキュレーション型EC」。** とくに「中古のオーダースーツ」は、品質が高いのに最も安く手に入る（元の持ち主の体に合わせてあるため売れにくい）。ここが一番の仕入れ源になる。

---

## 1. 構造の整理

### バリューチェーン
```
調達 → 査定・選別 → クリーニング・修繕 → お直し → 販売 → （回収・再流通）
```

### 考えられる事業モデル（顧客が何にお金を払うかで分類）

| # | モデル | 顧客が払うもの | 粗利 | 拡大のしやすさ | 判定 |
|---|---|---|---|---|---|
| A | **仕立て直し販売**（解体・再裁断・再縫製）＝当初案 | 新品同様に仕立て直したスーツ | × 工賃が売価を食う | × 職人の手作業が1着ずつ必要 | **不採用** |
| B | **中古＋サイズマッチング＋軽微なお直し** | 「自分に合う」良いスーツを安く | ◎ 50%前後 | ○ お直しを最小化すれば拡大できる | **本命** |
| C | 持ち込み型のリフレッシュ・お直しサービス | 自分のスーツの再生 | ○ | △ 既存のお直しチェーンと正面から競合 | 補完的なサービスとして |
| D | 委託販売（個人の出品を預かり、採寸・お直し付きで売る） | Bと同じ | ○ 手数料型 | ◎ 在庫を持たない | Bが回り始めたら移行 |
| E | レンタル・サブスク（就活・冠婚葬祭） | 一時的な利用 | ○ | △ 物流と在庫の管理が重い | 対象外 |
| F | 輸出・業者間のバルク取引 | 量 | × 薄利 | ○ | 対象外 |

## 2. 需要の分析

### 市場の大きな流れ
| 観点 | 事実 | 示唆 |
|---|---|---|
| スーツ市場 | 縮小傾向。2019年4〜6月期、青山商事のスーツ販売着数は前年同期比9.3%減。ビジネスウェアのカジュアル化が原因と報じられた。日本のスーツ市場は2024年に約17億ドル（B2Cの推計）で、今後はほぼ横ばいの予測 | 「スーツを着る人を増やす」事業ではない。限られた需要の中で、取り合う対象を選ぶ必要がある |
| リユース市場 | 拡大傾向。国内のリユース市場は2023年に約3.1兆円で、衣料・服飾品が5,913億円で最大。ファッションリユースは2023年に1兆1,500億円（前年比13.9%増）。政府は2030年に2024年比で32%の拡大を目標にしている | 「中古の服を買う」ことへの抵抗は下がり続けている |
| 海外の動き | 高級テーラードの中古は定価の50〜90%引きで売られている（販売者側の主張）。米英では、お直し職人の需要が伸びる一方で人手が不足 | 「中古の高級スーツ＋お直し」は海外でも成立しつつある。一方、お直しの供給能力が拡大のボトルネックになる |

### 誰が買うか（セグメント）
| セグメント | ニーズ | 支払意思 | 判定 |
|---|---|---|---|
| **クラシック服好き**（30〜50代、既製服では満足できない） | 海外ブランドや手縫いの仕立てを、手の届く価格で。体に合うことへのこだわりが強い | 高い（3〜6万円） | **主要ターゲット。** 数は少ないが、目利きと採寸の価値を最も理解する |
| 若手のビジネスパーソン | 「ちゃんとしたスーツ」を安く | 低い（2〜4万円） | 量販店の新品やパターンオーダーと競合し、中古への抵抗感もある。2番目の対象 |
| 冠婚葬祭・就活 | たまにしか着ない | 低い | レンタルや量販店で済ませる。対象外 |
| サステナビリティを重視する層 | 環境への配慮 | 中程度 | 主な購入理由にはなりにくいが、ブランドの物語として効く |

### 需要の最大の壁は「サイズが合うか分からない」こと
中古スーツがオンラインで売れにくいのは、①体に合うか分からない、②状態が分からない、③衛生面の不安、の3つのため。①が最大の壁で、**これを解消することこそが価値になる**：
- すべての商品を実寸で採寸し、購入者の採寸データ（または手持ちのスーツの寸法）と照らし合わせる
- お直し込みの価格にし、合わなければ返品できるようにする

### 「自分に合う寸法を知る」ことは解けるボトルネックである（2026-10-31追記）

需要側の最大のボトルネックは、購入者が自分に合う寸法を知らないこと。ただし、次の3点から、解ける問題であり、解いた者が価値を取れる。

1. **測るべきなのは、体の寸法ではなく、服の寸法**：体を自分で測るのは不正確で、ゆとりや好みも反映されない。手持ちの「よく合うジャケット」を平置きで測るほうが、簡単で正確
2. **測るのは、お直しで直せない箇所だけでよい**：肩幅・身幅・着丈の3か所だけ。袖丈・裾・ウエストは、お直しで合わせればよい。これで、購入者の手間は数分で済む
3. **主要ターゲットほど、もともと寸法を知っている**：クラシック服好きは、自分のサイズを把握していることが多い。このボトルネックが大きいのは、一般層に広げる段階

**設計への反映：**
- 「直せない3か所を測る」手順を、写真つきのガイドで提供する（手持ちのジャケットがない人向けに、標準のサイズ表からの推定も用意する）
- サイズが合わなかった場合の返品を保証し、返品の理由を記録する
- 「この寸法の人は、この服が合った・合わなかった」というデータが溜まるほどマッチングの精度が上がり、それが参入障壁になる

### 競合（購入者から見た代替品）
| 代替品 | 価格の目安 | 本命モデルBの勝ち筋 |
|---|---|---|
| 量販店の新品 | 2〜4万円 | 生地と仕立ての「格」（海外ブランドや手縫い）で勝つ |
| 新品のパターンオーダー | クロス・ゼニアやロロピアーナなどの生地で1着74,800円から（グローバルスタイル、2025年3月） | **価格**で勝つ（3〜5万円）。ただし、生地の良さだけでは勝てない |
| 中古品（2nd STREET、RAGTAG、メルカリなど） | 数千円〜数万円 | **サイズの安心感**（採寸・マッチング・お直し込み）で勝つ |

**含意：** 新品のパターンオーダーで、良い生地のスーツが7〜8万円で買える時代に、「良い生地」だけでは中古品の価値になりにくい。価値になるのは**「ブランドや仕立ての格」×「価格」×「サイズの安心感」**の組み合わせ。

## 3. 供給の分析

| 観点 | 事実 | 示唆 |
|---|---|---|
| 量 | 家庭から手放される衣類は年間73.1万トンで、その64%が廃棄されている（環境省、2022年） | 物量は豊富。問題は量ではなく、**良いものを見つけて選ぶ手間** |
| 量販店のスーツ | 買取価格は1,000円前後以下、または買取不可が多い | 安いが、仕立て直す価値も、高く売る価値もない。対象外 |
| 海外の高級ブランド | 買取価格の相場は約5,000〜40,000円 | 価値はあるが、コメ兵や2nd STREETなどの大手と仕入れで競合する |
| **中古のオーダースーツ** | **「売れにくい商品」とされ、買取をしない店もある** | **品質が最も高いのに、最も安く手に入る。** 安い理由は「元の持ち主の体に合わせてあること」だけ。採寸でのマッチングは、まさにこの問題を解消する。**最大の機会** |
| 個人間売買（メルカリ、ヤフオクなど） | 出品者の多くは寸法・生地・ブランドの価値を正しく伝えられていない | 生地のネーム（例：「Ermenegildo Zegna」の織りネーム）やブランドを写真から判別し、価格の歪みを拾う。**AIエージェントを活かしやすい** |

**供給側の制約：**
- すべてが一点物で、状態（虫食い、テカリ、擦れ）がばらつく
- サイズに偏りがある
- 偽物が混じるリスクがある（海外ブランド）

## 4. 収益性の比較（1着あたり、目安）

お直しの料金は一般的な目安で、実際の見積もりで要確認。

| 項目 | A：仕立て直し | B：マッチング＋軽微なお直し |
|---|---|---|
| 仕入れ | 5,000円 | 6,000円（中古のオーダースーツ、海外ブランド） |
| クリーニング・軽い補修 | 3,000円 | 3,000円 |
| お直し | **50,000〜100,000円**（解体・再裁断・再縫製。新規に仕立てるより手間がかかるという専門家の見解がある） | **約4,000円**（袖丈・裾・ウエストのみ。外注） |
| 採寸・撮影・出品・送料 | 3,000円 | 3,000円 |
| **原価合計** | **約6〜11万円** | **約1.6万円** |
| 売価 | 10万円以上が必要 → 新品のパターンオーダー（約7.5万円）に負ける | 39,800円 |
| 販売手数料（5〜10%） | ― | 約2,000〜4,000円 |
| **粗利** | **成立しない** | **約2万円（粗利率50%前後）** |

**お直しの料金の確認（2026-10-31追記）：** オーダースーツ専門店のダンカンは、他店で購入した品の直しで、パンツの裾1,980円〜、ジャケットの袖丈7,150円〜（税込）を掲示している。袖丈・裾・ウエストを合わせると約1万円になり、上の試算（約4,000円）より高い。小売価格で外注した場合、Bの粗利は約1.4万円（粗利率35%前後）に下がる。業者間の単価交渉と、お直しが不要な商品の比率を上げることが、より重要になる。

**比較から言えること：** 肩幅・着丈・身幅のように大きく直す作業ほど、工賃が跳ね上がる。**利益はお直しの量に反比例する**ので、事業の核心は「お直しをいかに減らすか」、つまりマッチングの精度にある。

## 4.5 狭義の競合（2026-10-31追記）

**結論：** 「中古スーツ × 採寸マッチング × お直し込み販売」を一体で提供する事業者は、検索した範囲では見つからなかった。ただし、検索で存在しないことは証明できないので、メルカリなどで実地に確認する必要がある。それぞれの要素ごとには、競合がいる。

| 区分 | 事業者 | 内容 | 本命モデルBとの重なり |
|---|---|---|---|
| 中古の販売（実寸を掲載） | トレファク（TREFAC FASHION）、RAGTAG、ノースランドクローズ（英国のビンテージのビスポーク）、楽天の出品者、メルカリの個人 | 実寸を載せて中古を販売。お直しとマッチングはない | 仕入れでも販売でも直接ぶつかる。**事実上、最大の競合はメルカリの個人出品者** |
| 顧客のスーツの仕立て直し | encoton（紳士服リメイク）、aim-rose（オーダースーツのお直し） | 持ち込まれたスーツを作り変える | 当初案（モデルA・C）の直接の競合。販売はしていない |
| お直し | 青山（他店の購入品も可）、ダンカン、はるやま、楽天のお直し業者 | 新品・他店品のサイズ調整 | 競合ではなく、**外注先の候補** |
| 回収と素材の再生 | 高島屋「スーツ再生プロジェクト」（回収したスーツを生地に戻してカジュアル衣料に）、青山商事「WEAR SHiFT」（回収したスーツのポリエステルを再利用） | 再利用ではなく、素材のリサイクル | 現時点では重ならない。ただし**青山は「全国でのスーツ回収」と「全国のお直し網」を両方持っており、参入されると最も強い潜在的な競合** |
| 採寸データの活用 | オーダースーツ店の「愛用スーツを送って採寸・登録」するサービス | 新品の注文用 | マッチングの考え方は同じ。中古品への応用はまだ見当たらない |

**示唆：**
- 空いているのは「中古の高級テーラード」×「サイズの不安の解消」の組み合わせ
- 大手（青山、高島屋）の関心は、いまはリサイクル（素材）にあり、リユース（そのまま再販）ではない
- 守りは速さとデータ。先に採寸データとクラシック服好きのコミュニティを押さえる

## 5. 「大規模展開」の実現可能性

| 観点 | 評価 |
|---|---|
| 規模の経済が効く部分 | 仕入れの目利きのデータ、採寸のデータベース、お直しの外注単価の交渉、ブランドの信頼 |
| 規模の経済が効かない部分 | 1点ごとの採寸・撮影・検品（変動費が売上に比例して増える）、在庫のサイズの偏り |
| ボトルネック | **お直しの供給能力**。職人の不足と高齢化は海外でも報じられており、日本でも同様の可能性が高い（日本の統計は未確認）。→ マッチングでお直しを最小化し、お直しチェーンとの提携で確保する |
| 参入障壁 | 低い。2nd STREETやZOZOUSEDなどの大手が同じことをすれば真似できる。守りになるのは、①採寸とマッチングのデータ、②クラシック服好きのコミュニティとブランド、③目利き |
| 規模の見立て | 「大規模」より**「ニッチの優良事業」**が現実的。月100〜300着の規模（年商5,000万〜1.4億円程度）が、小さな会社の上限の目安（構造からの推定） |

## 6. 本命モデルBの設計

| 要素 | 設計 |
|---|---|
| 提供価値 | 「海外ブランドや手縫いの仕立てのスーツを、あなたのサイズに合わせて、新品の半額以下で」 |
| 仕入れ | 中古のオーダースーツと海外ブランド。メルカリ・ヤフオクと、古着の業者向け卸。売れ筋のサイズ（日本の規格でA5〜A6、AB5〜AB6前後）に絞る |
| 選別 | 状態の基準（虫食い・テカリ・擦れ）と、直せる範囲の基準（袖丈・裾・ウエストで合うもの）を明文化する |
| 販売 | 当初はメルカリShops、その後は自社EC（Shopifyなど）。全商品の実寸と、「この寸法なら合う」体型の目安を掲載する |
| お直し | 購入時に寸法を聞き、お直し込みで発送する。外注先と単価を固定する |
| 保証 | サイズが合わない場合の返品を受け付ける（返品率をKPIにする） |
| 将来 | 委託販売（モデルD）に移行し、在庫リスクを減らす。お直しの持ち込みサービス（モデルC）でリピートを作る |

### AIエージェントの活用余地（EC事業より大きい）
- **仕入れ**：メルカリなどの出品写真から、ブランド・生地ネーム・状態を判定し、相場との価格差を出す
- **採寸の正規化**：出品者ごとにバラバラな採寸の表記を統一し、マッチングに使えるデータにする
- **出品原稿**：生地・仕立て・ブランドの背景を、クラシック服好きに響く文章にする

## 7. 法的な前提
- **古物商許可が必要**：中古品を仕入れて売るには、公安委員会の許可（古物営業法）が要る。申請から許可まで1か月以上かかるので、最初に着手する
- **偽物のリスク**：海外ブランドは真贋を確認する。不明なものは扱わない
- **ブランドの表示**：軽微なお直しならタグはそのままでよい。大きく作り変える場合は、元のブランド名を表示しない（商標の問題）

## 8. ハードル（`docs/hurdles.md`）に照らした見立て
- ③（事業利益が月10万円）に必要な量は、**固定費をClaude代の月42,500円だけとして、月7〜8着**（1着あたり粗利2万円）。
- 1着あたりの作業時間を1.5〜2時間に抑えれば、月12〜16時間に収まり、時給の条件（月20時間以内）も満たせる。
- **小さく試すには、EC物販よりも有利な可能性がある**：粗利率が高く、新規ページで客が来ない問題も小さい（メルカリには中古スーツを探す人が最初からいる）。

## 9. EC物販事業との相乗効果（示唆）
「メンズのクラシック服飾」を共通のドメインにすると、2つの事業を1つのブランドに束ねられる。
- 中古のテーラード（この事業）
- 新品の手入れ用品（Amazonで、価格差のある中国製の商品：シューツリー、洋服ブラシ、木製ハンガーなど）

顧客、コミュニティ、ブランドが共通になり、ドメイン集中の戦略（`docs/strategy.md`）とも整合する。

## 10. 最小構成の検証案（MVP）
| 項目 | 内容 |
|---|---|
| 準備 | 古物商許可の申請（手数料19,000円、許可まで約1〜2か月）。お直しの外注先を2〜3店確保し、単価を確認 |
| 仕入れ | 売れ筋サイズのスーツ5着（中古のオーダースーツと海外ブランド）、予算約5万円 |
| 販売 | メルカリShopsで、実寸・体型の目安・お直し込みの価格を掲載 |
| 判定基準 | 30日以内に売り切れる割合、粗利率40%以上、返品率、1着あたりの作業時間1.5時間以内 |

## 11. 未解決の論点
1. お直しの実際の料金と、外注先の確保（地域によって大きく違う）
2. 中古のオーダースーツの仕入れ価格と、出回る量（メルカリで実際に確認する必要がある）
3. 購入者が「お直し込みの中古」に、どこまで払うか（価格の検証）
4. EC物販事業と並行するか、どちらかに絞るか（作業時間の配分）
