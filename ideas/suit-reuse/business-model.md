# 中古テーラード事業：最適なビジネスモデル（2026-10-31）

前提となる分析：`ideas/suit-reuse/analysis.md`

**問い：** ここまでの議論（仕立て直しは不採用、価格差の正体はサイズの不安、寸法の把握がボトルネック、仕入れの量と質が事業全体のボトルネック）を踏まえ、最適なビジネスモデルは何か。

**結論：「フィット起点の中古テーラード」**
顧客の「合う寸法」を先に預かり、その寸法に合う中古の高級スーツを探して、お直し込みで届ける。在庫を先に持つのではなく、**需要（寸法）を先に集めてから仕入れる**ことで、事業の2大ボトルネック（サイズの不安と、仕入れのリスク）を同時に解く。

---

## 1. 設計の考え方：4つの論点への答え

| 論点 | 議論で分かったこと | 設計上の答え |
|---|---|---|
| 何で価値を出すか | 仕立て直しは工賃が高く、新品のパターンオーダー（約7.5万円）に負ける | **お直しを最小化する。** 価値は「選ぶ」ことと「合わせる」ことで出す |
| 需要側のボトルネック | 購入者は自分に合う寸法を知らない。アパレルECの返品理由で最も多いのはサイズ | **フィット・パスポート**：手持ちのジャケットの、直せない3か所（肩幅・身幅・着丈）を測って登録してもらう |
| 供給側のボトルネック | 中古は一点物で、サイズが偏る。在庫を持つと、売れないサイズが残る | **需要が先、仕入れが後**：登録された寸法に合う商品を、市場から探して仕入れる |
| 信頼 | 古着を買う人の約半数が衛生面を不安に感じている。購入に抵抗のある人が過半数 | プロのクリーニングを全品に実施し、状態を正直に開示し、サイズが合わなければ返品を受け付ける |

## 2. ビジネスモデルの全体像

### 誰に（ターゲット）
| 段階 | ターゲット | 理由 |
|---|---|---|
| 初期 | **クラシック服好きの30〜50代男性**（既製服に満足できないが、オーダーの高さには抵抗がある） | 自分の寸法を知っている人が多く、目利きの価値を理解する。コミュニティ（SNS、専門メディア）で届けやすい |
| 拡大期 | ちゃんとしたスーツを安く持ちたいビジネスパーソン | フィット・パスポートで、寸法を知らない層にも広げる |

### 何を（提供価値）
**「海外ブランドや手縫いの仕立ての1着を、あなたの寸法に合わせて、新品の半額以下で」**
- 新品のパターンオーダー（約7.5万円）より安い：3〜5万円
- 一般的な中古より安心できる：寸法の保証、プロのクリーニング、お直し込み

### どうやって（4つの仕組み）

```
① フィット・パスポート：顧客が寸法を登録（直せない3か所＋好み＋予算）
        ↓
② ハント：その寸法に合う中古品を、エージェントが市場から探し、候補を提示する
        ↓
③ 仕上げ：クリーニング → 補修 → 袖丈・裾・ウエストのお直し（上限つきで料金に含む）
        ↓
④ 循環：買い替えのときに下取りし、次の顧客に回す（仕入れ源になる）
```

| 仕組み | 内容 | 参考になる先行事例 |
|---|---|---|
| ① フィット・パスポート | 手持ちのよく合うジャケットを平置きで測る手順を、写真つきのガイドで案内する。うまく測れない人には、ジャケットを送ってもらって採寸する（有料、または初回購入で返金） | Suitsupplyの「Size Passport」（寸法を保存し、オンライン注文のお直しに使う）、国内のオーダースーツ店の「手持ちのスーツを送って採寸」 |
| ② ハント | 寸法・好み・予算に合う候補を3着まで提示する。売れ筋のサイズは在庫としても持つ（ハント＋在庫のハイブリッド） | ― （国内では見当たらない） |
| ③ 仕上げ | 料金にはお直し代の上限（例：8,000円）までを含め、超える分は顧客の負担。中古品はお直しの前にドライクリーニングを済ませる | Surmesur（遠隔で採寸した顧客に、一定額までのお直しを含める）、Neiman Marcus（着用済みの服は、お直しの前にドライクリーニングが必要） |
| ④ 循環 | 自社で買った顧客のスーツを下取りし、寸法のデータごと次の顧客へ回す | ブランドが自ら運営する再販（Patagoniaなど） |

### 収益モデル
| 収益源 | 内容 | 段階 |
|---|---|---|
| 販売の粗利 | 中古品の販売（お直し込み） | 初期から |
| ハント手数料 | 候補探しの手数料（購入時に販売価格へ含める） | 初期から |
| 委託販売の手数料 | 個人の出品を預かり、採寸・仕上げをして販売する（手数料25〜35%を想定） | 拡大期（在庫リスクを減らす） |
| お直し・リフレッシュ | 顧客が持ち込んだスーツのクリーニングとお直し | 拡大期（リピートと下取りの入口） |

## 3. 仕入れの設計

| 仕入れ先 | 価格の目安 | 位置づけ |
|---|---|---|
| **メルカリなどの個人出品**（中古のオーダースーツ、海外ブランド） | スーツ全体で、状態の良い品の平均は約8,600円。オーダー品は買取店でも約5,000円が目安で、断る店もある | **初期の主力。** 出品者は寸法と価値を正しく伝えきれておらず、価格に歪みがある |
| 顧客からの下取り | 販売価格の一部 | 拡大期の主力。寸法のデータごと手に入る |
| 個人からの委託 | 仕入れ値0円（手数料型） | 在庫リスクのない調達 |
| 古着のベール卸（キロ単位） | 安いが、中身は開けるまで分からない | 不採用。スーツに特化したベールは見当たらず、選別の手間に見合わない |
| レンタル落ち | 画一的なリクルートスーツが中心 | 不採用。ターゲットの価値に合わない |

**規約上の注意：** メルカリなどのフリマサイトは、自動収集（スクレイピング）を規約で禁止している可能性が高い（要確認）。エージェントの役割は「人が保存検索で拾った候補を評価する」ことにとどめ、自動で巡回させない。

## 4. 収益性（1着あたり）

お直しの料金は、ダンカンの小売価格（袖丈7,150円〜、裾1,980円〜）をもとに、お直しが不要な商品も含めた平均として置いた。

| 項目 | 金額 | 前提 |
|---|---|---|
| 売価 | 39,800円 | 新品のパターンオーダーの約半額 |
| 仕入れ | −7,000円 | 中古のオーダースーツと海外ブランドの平均 |
| クリーニング・補修 | −3,500円 | プロのドライクリーニングと軽い補修 |
| お直し（平均） | −6,000円 | 4割はお直し不要、残りは平均約1万円。業者間の単価交渉が進めば下がる |
| 送料（お直しの往復＋顧客への発送） | −2,500円 | |
| 販売手数料 | −4,000円 | メルカリShopsの10%。自社ECなら4%前後に下がる |
| 返品引当 | −600円 | 返品率15% × 1回あたりのコスト約4,000円 |
| **粗利** | **約16,200円（41%）** | |

**感度（粗利への影響が大きい順）：**
1. お直しの平均額：お直しが不要な比率が4割から6割に上がれば、粗利は+2,000円
2. 販売チャネル：自社ECに移れば、粗利は約+2,400円
3. 仕入れ値：目利きで3,000円安く買えれば、粗利は+3,000円

## 5. 基本指針（`docs/hurdles.md`）に照らした見立て

| 段階 | 必要な規模 | 作業時間 |
|---|---|---|
| ① 検証 | 6〜8着を売り、実績の粗利率35%以上を目指す | ― |
| ② 自走（時給5,000円） | 固定費をClaude代の月42,500円のみとし、月10時間の作業なら、粗利を約9.3万円 → 月6着 | 1着あたり1.5時間以内に抑える |
| ③ 安定（事業利益が月10万円） | 粗利を約14.3万円 → **月9着** | 約14時間（月20時間以内に収まる） |

**含意：** 月10着前後で③に届く。Amazon物販（③には月120〜190個の販売が必要）より、**小さな量で基準に届く**。その代わり、1着ごとの作業（検品・採寸・撮影・発送）が重いので、**1着1.5時間以内**を守れるかが鍵になる。

## 7. 段階的な計画

### Phase 0：準備と需要の検証（11月〜12月中旬）
| # | 担当 | タスク | 理由 |
|---|---|---|---|
| 0-1 | 🧑 | **古物商許可を申請**（手数料19,000円、審査は約40日） | クリティカルパス。許可がないと、仕入れて売ることができない |
| 0-2 | 🤖🧑 | フィット・パスポートの採寸ガイドを作り、知人5人で精度を試す | 寸法を正しく測ってもらえるかが、モデルの前提 |
| 0-3 | 🤖🧑 | 登録ページを作り、SNSで寸法の事前登録を募る（販売はしない） | 在庫を持たずに需要を測る |
| 0-4 | 🧑 | お直しの外注先を2〜3店確保し、業者としての単価を確認 | 粗利への影響が最大の変数 |
| 0-5 | 🧑 | クリーニングの外注先を確保 | 衛生面の不安への対応 |

**ゲート：** 4週間で、寸法の事前登録が30人以上 → Phase 1へ。届かなければ、ターゲットか打ち出し方を見直す

### Phase 1：最小構成の検証（許可の取得後〜2か月）
| 項目 | 内容 |
|---|---|
| 仕入れ | 登録された寸法に合うものを中心に6〜8着（予算約6万円） |
| 販売 | 事前登録者への個別の提案と、メルカリShops |
| 判定基準 | 30日以内に6割以上が売れる、実績の粗利率35%以上、返品率15%以下、1着あたりの作業時間1.5時間以内 |

### Phase 2：自走（月6〜10着）
- 自社ECに移り、フィット・パスポートを会員の機能として組み込む（古物商のURLの届出が必要）
- 下取りを始める
- 撮影・採寸・原稿を外注し、1着あたりの作業時間を減らす

### Phase 3：拡大
- 委託販売で在庫リスクを減らす
- お直しの外注網を広げ、地域を広げる
- 「直せない3か所」と、合った・合わなかったのデータを蓄積し、マッチングの精度を上げる

## 7.5 スカウト（ディグ）制度（2026-10-31追記・Phase 2以降）

**概要：** 登録された寸法（需要）を匿名で公開し、合う商品を見つけて報告した人（スカウト）に、成約したら報酬を払う。

**評価：有効。仕入れという事業全体のボトルネックを、自分の作業時間を増やさずに広げられる。** ただし、MVPでは使わず、Phase 2から導入する。

| 観点 | 評価 |
|---|---|
| 効果 | 探す作業を外部化できる。報酬は成約したときだけ払う変動費。人が目で探すので、フリマサイトの自動収集の規約問題も避けられる |
| 担い手 | クラシック服好き（＝顧客自身）が最適。目利きができ、探すこと自体を楽しむ。顧客がスカウトにもなる循環を作れる |
| 先行事例 | BUYMA（個人のパーソナルショッパーが商品を見つけて出品し、注文が入ってから買い付ける）。「需要を先に公開して探してもらう」形は、スーツでは見当たらない |

### 設計の要点
| 要点 | 設計 | 理由 |
|---|---|---|
| スカウトの役割 | **情報（出品のリンク）の提供だけ**とする。購入するのは自社 | スカウトが仕入れて自社に売ると、スカウト側に古物商許可が必要になる可能性がある（営利目的で反復継続する売買は許可が必要）。情報提供への報酬が許可の対象になるかは、所轄の警察署に確認する |
| 報酬 | **成約し、返品期間が過ぎてから支払う**。目安は粗利の15〜20%（1着2,500〜3,000円） | 質の低い報告の乱発を防ぐ。自社の粗利は約1.3万円（33%）に下がるが、自分の探す時間がなくなる |
| 報告の形式 | 直せない3か所の寸法、写真、価格を決まった形式で報告してもらい、エージェントが一次審査する | 審査の手間を自分に戻さない |
| 不正の防止 | スカウト自身の出品の報告は禁止し、相場より高い出品は報酬の対象外にする。報告の精度でスカウトを格付けする | 自作自演（自分の出品を高値で紹介する）を防ぐ |
| 個人情報 | 公開する寸法は匿名化し、顧客を特定できない形にする | 体型の情報は、本人が知られたくない情報 |

### 導入のタイミングと採算
- **導入の条件：** 自分とエージェントだけでは埋められない「探してます」（未成約の寸法登録）が溜まり始めたとき。需要がないと、スカウトは探すものがない
- **基本指針との関係：** 報酬を払うと、③に必要な販売数は月9着から約11着に増える。一方で、探す時間がなくなれば、1着あたりの作業時間は約1.5時間から約1時間に下がる。時給の条件に対しては、むしろ有利になる

## 7.6 将来の構想メモ（2026-10-31）

**体験の演出：リアルタイム更新の「ハンティング感」「オークション感」「ライブ感」**
- 例：スカウトの発見がリアルタイムで流れるフィード、寸法に合う1着が見つかった瞬間の通知、希少な品の時間限定の販売やライブ配信での紹介
- ねらい：中古の一点物という性質（同じものが二度と出ない）を、弱みではなく「出会いの楽しさ」に変える。クラシック服好きのコミュニティを活性化させ、再訪の理由にもなる
- 注意：**自社の在庫を競りの形式で売るのは通常の販売**だが、**他人の出品を競りにかける場を運営する場合は、古物営業法上の「古物競りあっせん業」の届出が必要**になる（委託販売に広げるときに要確認）
- 導入の時期：スカウト制度と寸法登録者が一定数そろってから（盛り上がる母数がないと、ライブ感は出せない）

## 8. 参入障壁（守り）
| 障壁 | 内容 |
|---|---|
| フィットのデータ | 「この寸法の人には、この服が合った・合わなかった」のデータは、時間をかけないと貯まらない |
| 寸法の登録者という資産 | 先に寸法を預かった顧客がいるほど、仕入れの精度が上がり、売れ残りが減る |
| 目利き | 生地・仕立て・ブランドの判別。エージェントに学習させて、属人化させない |
| コミュニティ | クラシック服好きとの関係。大手（青山など）には作りにくい |

## 9. 主なリスクと対策
| リスク | 対策 |
|---|---|
| 仕入れの量と質が足りない | 下取りと委託で、仕入れ源を増やす。ハント型で、売れないサイズを抱えない |
| 衛生面の不安 | 全品にプロのクリーニングを実施し、その旨を明示する |
| 偽物の混入 | 真贋が確認できない海外ブランドは扱わない。中古のオーダースーツ（偽物のリスクが低い）を主力にする |
| 作業時間が膨らむ | 1着1.5時間をKPIにし、超えたら外注に移す |
| 季節による偏り | 春（新生活）と秋に需要が寄る。生地の季節（春夏・秋冬）に合わせて仕入れを前倒しする |
| 大手の参入（青山など） | フィットのデータとコミュニティで先行する |
| フリマサイトの規約 | 自動収集はしない。人が保存検索で拾い、エージェントは評価だけを担う |

## 10. 未解決の論点
1. **EC物販と、どちらに作業時間を配分するか**：どちらも月20時間の枠を使う。古物商の審査期間（約40日）を使って、Amazon物販のPhase 0〜1と並行して需要を検証し、データが出た時点（12月中旬）でどちらに集中するかを決めるのが合理的
2. フィット・パスポートで、一般の人がどこまで正確に測れるか（Phase 0で検証）
3. お直しの業者間の単価（Phase 0で確認）
4. 中古のオーダースーツが、登録された寸法に合うものとして、月に何着見つかるか
