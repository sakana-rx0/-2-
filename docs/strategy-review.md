# 事業評価と座組の最適化（2026-10-22）

**状態：** 2026-10-22 に採用（`data/decisions.md`）。出品までの期限は、輸送の日数を考慮して6週間から7週間に修正した（`docs/roadmap.md`）。

**問い：** 「まずやってみる」を前提に、成果と成功確率を最大化する座組は何か。

**結論：** 事業として**やる価値はある**。ただし、現在の座組には**検証そのものを無効にしかねない欠陥が3つある**（仕入れ先の前提、新しい商品ページに客が来ない問題、差別化の欠如）。この3つを潰す形に座組を組み替え、予算を「2回試せる」設計にすれば、成功確率を最も高められる。

---

## 1. 全体の構造

| 層 | 現状 |
|---|---|
| **目的** | 時給5,000円以上で、月10万円の事業利益を得る（`docs/hurdles.md`）。ECは複数あるビジネスアイデアの1つ |
| **事業モデル** | 中国製の小ロット品 → Amazon.co.jp（FBA）。価格差のあるニッチなドメインに集中し、独自ブランドとして展開 |
| **実行体制** | AIエージェント（リサーチ・評価・出品原稿）＋人間（決裁・検品・法的判断・公開承認） |
| **判断ルール** | ①検証 → ②自走 → ③安定の3段階と、それぞれの期限 |
| **資源** | 予算10万円（仮）、作業時間は月20時間以内、Claude Max（月42,500円） |

## 2. 評価

| 観点 | 評価 | 根拠 |
|---|---|---|
| 市場性 | ○ | ニッチな趣味用品は、専門店との価格差が残っている領域がある |
| 収益性 | △ | 売価4,000円・粗利率30%で1個あたり約1,200円。③には月120〜190個の販売と、約50万円の在庫資金が必要 |
| 参入障壁 | × | 中国輸入物販は副業として広く知られたモデル。さらに、**中国の業者自身がAmazon.co.jpで直接販売しており、原価の面で勝てない** |
| あなたの優位性 | ○ | ①AIエージェントで、調査と出品原稿の作成を安く速く回せる。②ブランドとマーケティングの知見を使える |
| 撤退コスト | ◎ | 最大でも予算と時間の範囲に収まる。在庫も少量 |

**総合：** 「低リスク・中リターン・参入障壁なし」の事業。勝ち筋は、**価格ではなく、選定眼・日本語での品質・ブランドで勝つ**ことと、**AIで試行回数を増やす**ことの2つしかない。

**成功確率の見立て**（業界の統計ではなく、構造から判断したもの）
- ①：座組を直せば「中〜高」
- ②：「中」。品揃えを5〜10品に広げられるかで決まる
- ③：「低〜中」。差別化が積み上がるかで決まる

## 3. 検証を無効にしかねない3つの欠陥

### A. 仕入れ先の前提（最重要・要確認）
7sGoodは、香港のHHO Limitedが運営する**消費者向けのショッピングアプリ**であり、卸売サイトではない。
- **価格**：小売価格のため、卸値より高く、粗利を圧迫する
- **法的なリスク**：個人として輸入したものを転売すると、関税（個人使用を前提にした課税価格の軽減）や、輸入者としての責任の面で問題になりうる
- **規約**：転売を禁止していないか、確認が必要

→ **組み替え：** 7sGoodは**商品の発見とサンプルの購入**に限る。本番の仕入れは、**1688（中国の卸サイト）など＋日本の輸入代行業者**（小ロットに対応している業者がある）で行う。

### B. 新しい商品ページに客が来ない（コールドスタート）
現在の座組は「独自ブランドで新規ページを作成」かつ「小口出品で広告なし」だが、この組み合わせは矛盾している。レビューも広告もない新規ページは、検索結果にほぼ表示されない。そのため、テスト販売で売れなかったとしても、**商品が悪いのか、単に見つけてもらえなかったのかを区別できない**。

→ **組み替え：** テスト販売の期間だけ**大口出品＋Amazonブランド登録**で臨む。
- 大口でブランド登録した新規出品者には、**新規出品者特典**（Amazon Vine（レビューを集める仕組み）のクレジット、スポンサー広告のクレジット、売上の一部還元など）がある。2022年時点の情報なので、**最新の条件はセラーセントラルで要確認**
- 特典が使えれば、追加の費用（大口の月額＋広告費）の大部分を相殺できる
- このために、商標の出願を「ゲートBのあと」から「**ブランド名を決めた直後**」に前倒しする

### C. 差別化がない
同じ工場の同じ商品を、中国の業者が安く売っている。単品で価格勝負をすれば負ける。

→ **組み替え：** 小ロットでもできる差別化を、最初から組み込む。
- **セット化**（例：本体＋ケース＋クロス＋日本語の説明書）：同じ商品との価格の直接比較を避けられる
- **全数検品と日本語でのサポート**を、ブランドの約束として明記する
- 原稿とページの質（エージェントの強み）で、商品ページの購入率を上げる

## 4. 最適化した座組

| 要素 | 現在 | 最適化後 | 理由 |
|---|---|---|---|
| 仕入れ | 7sGood | **発見・サンプル＝7sGood、本番の仕入れ＝1688など＋輸入代行** | 原価と法的なリスク（欠陥A） |
| 出品形態 | 小口・広告なし | **テスト期間は大口＋ブランド登録＋新規出品者特典** | 新規ページの集客（欠陥B） |
| 商標 | ゲートB以降に出願 | **ブランド名を決めた直後に出願**（1区分で出願料約1.2万円） | ブランド登録の前提になる |
| 商品 | 単品 | **セット化と日本語の付加価値** | 価格競争を避ける（欠陥C） |
| ドメイン選定 | 市場の基準のみ | **「自分が詳しい・好きか」を加点**に追加 | 創業者と市場の相性は、選定眼と原稿の質に直結する |
| 予算 | 10万円で1回 | **15万円で2回試す**（1回目に約10万円、2回目の余力として約5万円） | 1回の検証の成功確率は高くない。試行回数が成功確率を決める。商標とJANコードは2回目以降も使い回せる |
| 広告費の扱い | 未定義 | 立ち上げ期の広告費と値引きは**「検証費」として別枠で計上**し、ハードル①は広告費を含めた場合と除いた場合の両方で記録する（判定期間の前に定めておく） | 合格ラインの後付けを防ぎつつ、立ち上げの特殊要因と区別する |
| 速さ | ドメイン選定 → 候補出し → … | **ドメイン選定は1週間、出品までは7週間を上限**とする | 「まずやってみる」。机上の検討を長引かせない |
| Claude代 | EC事業が全額を負担 | ハードル判定は全額負担のまま（保守的）。ただし、Claude Maxを複数の事業アイデアで使うなら、**事業アイデア全体で回収すべき費用**として別途管理する | ECの判断に使う数値は厳しめに保ちつつ、AIによる事業運営の基盤そのものを、資産として評価する |

### 費用の見込み（1回目）
| 項目 | 金額 |
|---|---|
| サンプル（3品 × 2〜3個） | 約1.5万円 |
| テスト仕入れ（3品 × 10個） | 約6万円 |
| 商標の出願（1区分） | 約1.2万円 |
| JANコード（GS1 Japan） | 約1〜2万円（要確認） |
| 大口の月額 × 2か月 | 約1万円 |
| 広告費 | 約2万円（新規出品者特典のクレジットで相殺できる可能性あり） |
| **合計** | **約12〜14万円**（特典を使えれば約10万円） |

## 5. 未解決の論点
1. **7sGoodの利用規約と仕入れ価格**：卸として使えるか（欠陥Aの確認）
2. **新規出品者特典の現在の条件**：セラーセントラルで確認する
3. **予算を15万円に上げるか**：2回試すための余力
4. **小口から大口への変更**：テスト期間だけ大口にする提案。月4,900円の固定費は、テスト期間中は検証費として扱う
