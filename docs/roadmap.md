# MVPロードマップ

目的：開業届を出す前に「売るもの」と「売る仕組み」の目処を、最小コストで検証する。座組の根拠は `docs/strategy-review.md`。

凡例：🧑 = 人間（判断・決裁・実物確認）／🤖 = エージェント／✅ = 完了

## 座組（2026-10-22 採用）

| 要素 | 内容 |
|---|---|
| 仕入れ | 商品の発見・サンプル＝7sGoodなど／本番の仕入れ＝1688など＋日本の輸入代行業者 |
| 出品形態 | テスト期間は**大口出品＋Amazonブランド登録**。新規出品者特典（広告・Vineのクレジット）を活用 |
| 商品 | ドメインを1つに絞り、3品×10個。セット化と日本語の付加価値で差別化 |
| 予算 | **15万円で2回試す**（1回目に約10〜14万円、2回目の余力として約5万円） |
| 期限 | ドメイン選定は1週間、出品までは7週間（12月上旬）、ハードル①の判定は出品から8週間 |

## 優先順位の考え方

1. **時間がかかる外部手続きは最初に着手**（Amazonの審査、商標の出願、輸入代行業者の登録）。待ち時間に他の作業を並行する
2. **お金を使う前に判定基準を固定**。基準がないと、エージェントの提案を評価できない
3. **机上の検討は期限で打ち切る**。「まずやってみる」を仕組みで担保する
4. **自動化は採算を確認してから投資**。MVPは「エージェントが調査・作成し、人が承認する」半自動で回す

## Phase 0：基盤づくり（1週目：〜10/29）

| # | 担当 | タスク | 理由 |
|---|---|---|---|
| 0-1 | 🧑 | Amazon出品者登録を申請（**大口**） | 審査に数日〜数週間かかるクリティカルパス |
| 0-2 | 🧑 | 作業時間の記録（`data/timelog.csv`）を今日から始める | ハードル②の判定に必須 |
| 0-3 | 🧑 | 7sGoodの利用規約で、転売が許されているかを確認する | 欠陥A。サンプルの購入先として使えるかの確認 |
| 0-4 | 🤖 | 小ロットに対応した輸入代行業者を3社比較する（手数料、最小発注数、検品・セット化への対応） | 本番の仕入れルートを決める |
| 0-5 | 🧑 | 0-4の結果から輸入代行業者を選び、登録する | |
| 0-6 | 🧑 | 新規出品者特典の現在の条件をセラーセントラルで確認する（0-1の完了後） | 欠陥B。広告とVineの費用を相殺できるか |
| 0-7 | 🧑 | Keepaの無料のブラウザ拡張を入れる | 上位候補の推移を目視で確認するため |
| ✅ | 🤖 | 判定基準、粗利計算、ハードル判定、エージェント、決裁ログ、販売戦略、基本指針、座組の評価 | 全員の共通の物差しと体制 |

## Phase 1：商品検証（2〜4週目：〜11/19）

| # | 担当 | タスク |
|---|---|---|
| 1-0 | 🤖 | **ドメイン選定**：`/domain-selection` で3案を比較し、推奨案を出す（1週間以内） |
| 1-1 | 🧑 | **【ゲート：決裁】** ドメインとブランド名を決める → J-PlatPatで商標の空きを確認 → **すぐに商標を出願**（1区分で出願料約1.2万円） |
| 1-2 | 🤖 | 決めたドメインの中で候補を15品出し、上位3品に絞る（`/sourcing-cycle`）。セット化の案も合わせて出す |
| 1-3 | 🧑 | **【ゲート：決裁】** サンプル発注を承認する |
| 1-4 | 🧑 | 実物を検品し、実際のコスト（送料・関税・日数）を記録 → 🤖が再計算 |
| 1-5 | 🧑 | 商品の実物写真を撮影（メイン画像には実物写真が必須） |

**ゲートB：** 実際のコストで計算しても、判定基準を満たす商品が3品以上ある → 🧑 JANコードを取得（GS1 Japan）し、Amazonブランド登録を申請 → Phase 2へ。満たさなければ1-2に戻る。2周しても満たさなければ、ドメインを変える（1-0に戻る。2回目の試行として予算の残りを使う）

## Phase 2：テスト販売（5〜15週目：本発注 → 12月上旬に出品 → 8週間で判定）

| # | 担当 | タスク |
|---|---|---|
| 2-1 | 🧑 | **【ゲート：決裁】** 本発注（3品×10個、セット化を含む）→ 輸入代行業者からFBAに納品 |
| 2-2 | 🤖 | 出品原稿を作成（`listing-creator`）。ブランド登録が済んでいれば、商品紹介コンテンツ（A+）も作る |
| 2-3 | 🧑 | **【ゲート：公開承認】** 原稿を目視確認し、公開する |
| 2-4 | 🧑🤖 | Vineでレビューを集め、スポンサー広告を出す（新規出品者特典のクレジットを優先して使う） |
| 2-5 | 🤖 | 販売運用・会計エージェントを構築（まずはレポートCSVの集計。大口なのでSP-APIへの接続も可能） |

**ゲートC＝ハードル①（`docs/hurdles.md`）：** 実績粗利率20%以上、かつ8週間で7割以上が売れる → **開業届と青色申告の承認申請**（開業から2か月以内に提出）→ 大口を続けるかを判断 → ハードル②③へ。未達なら、2回目の試行（商品の入れ替え、またはドメインの変更）を決める

## 後回しにするもの（MVPの範囲外）

- 楽天への出店（固定費と運用負荷が重い）
- OEM（ロゴ入れなど、自社仕様での製造）：最低発注数量を満たせる規模になってから
- モール外の販促（SNS、専門メディア）：ドメインでシェアが取れ始めてから（`docs/strategy.md` の定義を参照）
- 仕入れ発注の完全自動化
- Keepaの有料版：手作業での確認がボトルネックになってから
