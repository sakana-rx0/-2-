# 仕入れ判定基準

全エージェントはこの基準で判定する。数値の閾値は `config/assumptions.toml` を正とする。

## 0. ドメイン選定（商品を選ぶ前に行う）

戦略の背景は `docs/strategy.md` を参照する。

| 指標 | 基準 | 理由 |
|---|---|---|
| 市場規模 | 主要キーワードで上位30品の推定売上の合計が、月300万円以上 | 小さすぎると、シェアを取ってもすぐ頭打ちになる |
| 大手の寡占度 | 上位10品のうち、大手ブランドが6品以下 | 新規のブランドでも食い込める余地 |
| 価格差の構造 | 専門店の価格が、中国製の代替品の想定原価の3倍以上ある商品が、ドメイン内に複数ある | 粗利の源泉 |
| 品揃えの幅 | 売価4,000円以上で除外条件に該当しない商品を、10品以上並べられる | ブランドとして一貫した商品群を作れるか |
| 季節性 | 通年で売れる、または季節の異なる商品で売上の偏りを相殺できる | 売上と資金繰りが特定の時期に偏らないようにする |
| コミュニティ | 専門のSNSアカウント、YouTubeチャンネル、専門メディアが存在する | モール外の販促でターゲティングしやすい |
| 拡大先 | 隣接するドメインがある（例：スキー用品 → スノーボード用品 → 冬のアウトドア用品） | シェアを取ったあとの広げ先 |
| 購買者の性質 | 仕様やこだわりで選ぶ層が多い | ブランドの信頼が購買理由になりやすい |
| 自分との相性（加点） | 自分が詳しい、または好きなドメインである | 選定眼と出品原稿の質に直結する |

## 1. 除外条件（1つでも該当すれば即NG）

| 区分 | 該当例 | 根拠法令など |
|---|---|---|
| 電気製品 | AC電源を使う製品、充電器、モバイルバッテリー | 電気用品安全法（PSE） |
| 無線機器 | Bluetooth、Wi-Fi、無線リモコン | 電波法（技適） |
| 食品に触れるもの | 食器、調理器具、水筒、乳幼児向けの玩具 | 食品衛生法（輸入時に届出が必要） |
| 肌・身体用 | 化粧品、コンタクトレンズ、マッサージ器 | 薬機法 |
| 特定製品 | 乗車用ヘルメット、ライター、圧力鍋 | 消費生活用製品安全法（PSC） |
| 危険物 | リチウム電池を内蔵した製品、スプレー缶 | FBAの危険物規定 |
| 知的財産 | ブランドのロゴ入り品、キャラクター品、有名品の模倣デザイン | 商標法、意匠法、Amazonの規約 |
| Amazonの制限 | 出品許可が必要なカテゴリ | Amazonの規約 |

判定に迷う場合は「要確認」とし、🧑が最終判断する（推測でOKにしない）。

## 2. 定量基準（すべて満たせばGO）

| 指標 | 基準 | 理由 |
|---|---|---|
| 粗利率 | 30%以上（計画値） | 為替・送料の変動と、値下げ競争に耐える余地。実績で10ポイント下がっても、ハードル①（実績20%）を満たせるようにする |
| 1個あたりの粗利 | 500円以上 | 低単価品は手間に見合わない |
| 販売価格 | 4,000〜15,000円 | 10個仕入れの場合、Amazon手数料・FBA手数料・国際送料だけで1個あたり約1,100円かかるため、4,000円未満では粗利率30%に届きにくい。高すぎるとテストの在庫リスクが大きい |
| 月間推定販売数（カテゴリ上位10品の中央値） | 100個以上 | 需要があることの確認 |
| 競合 | レビュー数1,000件超の出品が上位を独占していない | 新規の出品でも食い込める余地 |
| サイズ・重量 | FBAの小型・標準サイズ、1kg未満 | 国際送料とFBA手数料を抑える |
| 季節性 | 販売のピークまで8週間以上ある、または通年で売れる | 仕入れのリードタイム（2〜4週間）と検証期間の確保 |

## 3. 定性的な加点（優先順位づけに使う）

- **価格差の構造がある**：専門店では高価だが、中国製に同等品質の代替品がある（大人の趣味・スポーツ用品など）
- **スペックで比較できる**：素材や寸法など、仕様で品質を説明できる（画像と説明文で売りやすい）
- **壊れにくい**：返品・初期不良のリスクが低い
- **バリエーションが少ない**：色・サイズ展開が少ないほど、在庫を分散させずに済む
- **セット化できる**：ケース、交換部品、日本語の説明書などを同梱して、同じ商品との価格の直接比較を避けられる
- **ドメイン内の一貫性**：既存の（または同時に出す）商品と同じ顧客に売れ、まとめ買いや関連商品からの流入が見込める

## 4. 粗利の計算式

```
仕入れ原価（1個あたり） = 仕入れ値 + 国際送料 + 代行手数料 + 関税 + 輸入消費税
粗利 = 販売価格 − 販売手数料 − 基本成約料（小口のときだけ100円） − FBA手数料 − 広告費（定常時、売上の10%） − 返品引当 − 仕入れ原価
```

計算は `python3 tools/profit_calc.py <CSV>` で行う。FBA手数料は、セラーセントラルの「FBA料金シミュレーター」で調べた実額を入力する。
