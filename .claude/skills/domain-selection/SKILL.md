# ドメイン選定

方向性のヒント：$ARGUMENTS（例：「大人の趣味・スポーツ」。空欄なら制約なし）

## 手順
1. `docs/strategy.md` と、`docs/criteria.md` の「0. ドメイン選定」を読む
2. market-researcher エージェントに、ドメインの候補を8〜10個出させる。ドメインごとに、選定基準の各指標について根拠（出典URLまたは推定である旨）を集めさせる
3. 選定基準で採点し、上位3案に絞る。季節性と拡大先は必須の条件として扱う
4. 3案それぞれについて、代表的な商品を3品挙げ、`tools/profit_calc.py` でざっくり粗利を試算する（数値は推定でよいが、推定と明記する）
5. 推奨案を1つ選び、`data/research/YYYY-MM-DD-domain-selection.md` に書く

## 人間への提示形式
```
## 推奨ドメイン：○○
理由（3点以内）／主なリスク
## 比較表
| ドメイン | 市場規模 | 寡占度 | 価格差 | 品揃えの幅 | 季節性 | コミュニティ | 拡大先 | 代表商品の粗利率 |
## 決めてほしいこと
- ドメインをどれにするか
- ブランド名の方向性（`data/brand.md` に記入）
```

## 守ること
- ドメインの決定は人間が行う。決裁後に `data/decisions.md` と `data/brand.md` を更新する
- 根拠が取れない指標は「不明」と書き、高く評価しない
