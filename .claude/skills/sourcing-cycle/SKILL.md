# 仕入れサイクル

調査テーマ：$ARGUMENTS（空欄なら、`docs/criteria.md` の加点条件から market-researcher がテーマを立てる）

## 手順
1. **リサーチ**：market-researcher エージェントにテーマを渡し、候補を `data/candidates.csv` に追記させる
2. **評価**：sourcing-evaluator エージェントに、新しく追加された候補を評価させ、決裁用の提案書を作らせる
3. **決裁依頼**：提案書の要点を人間に提示する。形式は次のとおり
   - 発注案（商品 × 個数 = 金額、予算の残り）
   - 各候補の粗利と主なリスク（1行ずつ）
   - 人間が確認すべきこと（法規制の「要確認」、Keepaで確認してほしいキーワードやASIN）
4. `data/decisions.md` に「決裁待ち」として1行追記する

## 守ること
- 発注、出品、セラーセントラルの操作は行わない。決裁依頼を出したところで止まる
- GO判定の候補が0件なら、それ自体を結果として報告し、テーマを変える案を2つ示す
