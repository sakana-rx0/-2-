## 0. 結論（1分で読む版）

**問い：** 最初に感じた「退屈さ」と「選択肢が閉じていく怖さ」の正体は何か。どう生きれば解消できるか。

**答え：**
1. **正体は「軸がないこと」と、それを守る保険の仕組み。** 最大化すべき対象がないので、日々の行動は惰性で決まる。全力を出さず、計画と仕組みづくりにとどまることで、「自分ならできる」という自信が試されないように守ってきた。退屈さは、その副作用。
2. **処方は「小さく賭けて、証拠を積む」こと。** 根拠のない自信を、根拠のある自信に置き換える。そのために、判定日・審判・賭け金のついた短いゲームを、外の世界で回す。
3. **ルールは3本だけにする。** これまで、仕組みを増やすほど止まってきた。ルールブック自体が「新しい仕組み」になる危険があるので、核は3本に絞り、残りは補助とする。

**最初の一手（今週）：** 明朝、体重を測ってパートナーに送る。審判と賭け金を決めて、ゲーム1を始める。

## 1. 診断：なぜ今の状態になっているか

### 1-1. 因果のつながり

```
[A] 自分の基準がない
      ↓ 代わりに「誰が見ても上」を選ぶ（筑附・慶應・ユニリーバ・コンサル）
[B] 選択肢を残し、どれにも賭けない
      ↓
[C] キメ（自分で選び、退路を断つ）が生まれない
      ↓                                  ↑ 守っているもの
[D] 計画・仕組みづくりで止まる  ←───  [E] 「自分ならできる」という根拠のない自信
      ↓                                       （全力を出さなければ、試されない）
[F] 日々は惰性。証明すべき物語が増えない
      ↓
[G] 退屈さ・「語れることがない」・余暇への罪悪感
```

### 1-2. 各リンクの根拠と確度

| リンク | 根拠（本人の回答） | 確度 |
|---|---|---|
| A→B | 名の知れた学校・企業を選んだ理由は「選択肢を残す・認められたい・他に基準がなかった」 | 高 |
| B→C | キメが生まれたのは、自分で私立中を辞めた高校受験だけ。大学受験・弓道ではキメがなかった | 高 |
| E→D | 受験に落ちても「もっとできた」「うっすら落ちると思っていた」で自信は揺らがなかった。言い訳のきかないかけっこは避けた。この解釈に本人の違和感なし | 中〜高 |
| D | 10億円ログ・朝30分・モーニングブリーフ・Obsidian・家計管理・EC事業・減量プログラムは、どれも設計か着手の段階で止まった | 高 |
| F→G | 日々の行動の基準は「惰性」。軸がないので、余暇が「時間潰し」に感じる | 高 |

### 1-3. 専門的な裏づけ
- **セルフ・ハンディキャッピング：** 失敗が予想されるとき、努力を控えて「能力のせいではない」状態を作り、自己像を守る行動。159研究のメタ分析で、失敗への恐れ（r=.39）と強く結びつき、勤勉性（r=−.40）と負の関係にある（Schwinger et al., 2021）。D（計画で止まる）は、この行動の一形態と見なせる。評価される地点に永遠にたどり着かないからだ。
- **後悔の非対称性：** 短期的には「やったこと」の後悔が強いが、長期的には「やらなかったこと」の後悔が強く残る（Gilovich & Medvec, 1994）。本人が80歳で避けたい後悔（自分で賭けなかった）と一致する。

### 1-4. この診断が間違っている可能性（反証条件）
- 審判と賭け金を付けても、ゲーム1・ゲーム2の両方で行動量がほぼゼロなら、原因は保険ではなく、エネルギー不足（睡眠・体調・本業の消耗）の可能性が高い。その場合は、5章の判定日に「回復を軸にする」へ切り替える。

## 2. 指針（最上位）

> **主観で、生の感覚で、没頭して生きる。広い世界を体験する。それを踏まえて、子どもと家族にもベストな導きをする。**

この指針には、性質の違う2つの欲求が入っている。どちらか一方では満たされない。

| モード | 中身 | 意識の向き | 例 |
|---|---|---|---|
| 生の実感 | 評価のない、五感での外とのつながり | 外向き | 自然、新しい場所、食、身体 |
| 没頭 | 腕前とスコアが連動するゲームでの積み上げ | 内向き | 受験、弓道、カート、ゴルフ |

**含意：** 没頭のゲーム（仕事・事業）を、画面の前だけで完結させない。外の世界との接点（人と会う、売る、現場に行く）を必ず入れる。そうしないと、没頭できても「生きている実感」がない。

## 3. 核のルール（3本だけ）

### C1. 軸は1本。今の軸は「一人事業の実験」
- 軸とは、目標の数字ではなく **日々手を動かす対象**。
- 2027-03-31までの軸は、AIを使った一人事業の実験（5章 ゲーム2）。減量は軸ではなく、軸を支える土台。
- **合否は行動で判定する。** 空いた時間に最初に思いつく行動が、軸に関するものなら合格。
- 量の目安は週10時間。

### C2. 毎週、審判に数字で報告し、未達なら払う
- 審判は人間の他人（パートナー、または友人・同僚）。AIで作った仕組みには任せない。
- 毎週日曜の夜に、決めた数字（体重、軸の時間、実験の成果）を送る。
- 未達なら審判に払う金額を、ゲームを始める前に決める。痛いが、生活は揺らがない額にする（目安：1回5,000〜10,000円）。
- **根拠：** stickKの約40万件のコミットメント分析では、外部の審判と金銭の賭けを付けたものほど達成率が高く、最も成功したのは「6〜8週間・毎週報告・審判あり・賭け金あり」の組み合わせだった（ICWSM 2024）。審判も賭け金もない場合の成功率は約29%で、両方そろうと大きく上がるとする集計もある（stickK自社の数字のため参考値）。

### C3. 判定日と合格ラインは、始める前に決め、途中で下げない
- 始める前に「判定日・合格ライン・合格時と不合格時の行動」を書き、審判に送る。
- 期間中は合格ラインを下げない。延長もしない。
- 結果は、自分の能力への判決ではなく、**実験のデータ**として記録する。これが「限界を知る怖さ」を弱める（試されるのは能力ではなく、仮説だから）。
- 不合格の判定を受けたあと、次のゲームの合格ラインを見直すのは構わない。ただし、それは次のゲームを始める前に限る。

## 4. 補助ルール

|---|---|---|
| S1 | **考える時間は軸の時間の2割まで。** 答えは考えて出すものではなく、外で小さく試して見つける | 内側に閉じる、計画で止まる |
| S2 | **2027-03-31まで、新しいツール・仕組み・AIエージェントは作らない。** 例外は、事業として売るもの。このルールブックの改訂も、月末の見直し日だけに限る | 仕組みを作って止まる |

## 5. ゲームの予定（2026年11月〜2027年3月）

### 5-1. 全体の並べ方
同時に走らせるゲームが多すぎると、また止まる。11月は減量を主役にし、一人事業は助走（人と話すだけ）にとどめる。

| 期間 | 主役 | 助走・並行 | 外部の予定 |
|---|---|---|---|
| 10/29〜11/30 | ゲーム1：減量 | ゲーム2の助走（候補出し・5人と話す） | 11/3 Archetype Venturesと面談、転職の選考 |
| 12/1〜1/31 | ゲーム2 第1実験 | 減量の維持 | 12月 AI HACK 2026、年明けに上野毛へ引っ越し |
| 2/1〜3/31 | ゲーム2 第2実験（手応えのある方を深掘り） | ー | 3/31 判定日 |

### 5-2. ゲーム1：減量（〜11/30）

| 項目 | 内容 |
|---|---|
| 目標 | 2026-11-30の朝の体重が80.0kg以下（10/10に本人が設定した、譲らない目標） |
| 審判 | パートナー。毎朝の体重を写真で送る |
| 報告 | 毎日の体重＋毎週日曜に7日平均 |
| 賭け金 | 11/30に未達なら、審判に払う（金額は本人が決める） |
| 守ること | 1日1,900kcalの下限、たんぱく質の目標、朝の有酸素 |
| 誘惑の遮断 | 22時以降のスマホ（S3）、11月の会食は事前に断るか、メニューを先に決める |

**実現可能性の見積もり（正直な評価）：**
- 体重85kg・身長181cm・26歳男性の1日の消費は、活動量によって約2,600〜2,800kcalと推定できる。1,900kcalを守ると、1日の赤字は約700〜900kcal。
- 脂肪1kgは約7,200kcalなので、残り約33日で落とせる脂肪は約3.2〜4.1kg。最初の数日は、むくみや糖質の減少による水分で1〜2kg動くことがある。
- したがって、**今の体重が84kg前後なら届く可能性があるが、86kg以上なら完璧に実行してもかなり厳しい。** 明朝の計測で、まず現実の数字を確定させる。
- C3により、目標は途中で下げない。未達なら11/30に結果をデータとして記録する。12月以降の減量は、週に体重の0.5〜1%というペース（85kgなら週0.4〜0.85kg）を上限に、改めて合格ラインを設計する。

### 5-3. ゲーム2：AIを使った一人事業の実験（11月助走、12/1〜3/31本番）

| 項目 | 内容 |
|---|---|
| 判定日 | 2027-03-31 |
| 合格ライン | 判定日時点で、直近1か月の利益が約5万円 |
| 合格なら | 一人事業に軸足を移す。転職先も「一人事業を伸ばせる時間」を最優先に選ぶ |
| 不合格なら | 結果をデータとして記録する。転職を軸に据え直すか、得られた手応えをもとに次の実験を設計する |
| 時間 | 週10時間（平日夜1時間×4日＋週末6時間） |
| 審判 | 同僚または友人（減量とは別の人が望ましい）。毎週日曜に「軸の時間・話した人数・売上」を送る |

**11月の助走（減量の邪魔をしない範囲）：**
1. 候補を10個書き出す。今ある資産（消費財ブランドとトレードマーケの知見、オフライン配荷の構造理解、AIでのツール作り、EC物販の設計）を起点にする。
2. そのうち上位3つについて、買ってくれそうな人5人と話す。オンラインでもいい。外の世界との接点（S1）を最初から入れる。
3. 11月30日に、12月に試す1つを決める。

**実験の型：**
- 1本の実験は4〜8週間（コミットメント研究で最も成功しやすい長さに合わせる）。
- 各実験の合格ラインは「売上が立ったか」ではなく、第1実験は「お金を払ってくれた人が1人いるか」、第2実験は「月5万円の利益に届く再現性があるか」と段階的に置く。
- 少なくとも1つ、外部の枠に参加する。例：AI HACK 2026（2026年12月11〜13日、20代対象、個人応募可、応募締切12月9日）。

**正直な評価：** これまでの崩れるパターン（外部の枠がないと止まる）からすると、一人事業は、外部の枠が最も弱いゲーム。失敗のリスクは本業や転職より高い。それでも試す価値があるのは、本人が「本気で追ってみたい」と言った唯一の対象であり、腕前とスコアが連動するゲームだからだ。C2（審判と賭け金）を必ず付けることで、外部の枠の弱さを補う。

### 5-4. 判断：転職

| 項目 | 内容 |
|---|---|
| 位置づけ | 転職はしてもいい。本業は、一人事業と生活を支える土台 |
| 必須条件 | ①年収800万円以上 ②一人事業に週10時間を回せる ③一人事業に活きる経験が得られる |
| オファーが3/31より前に出たら | 必須条件の①〜③で判定する。③だけ満たして②を満たさない場合（長時間の仕事）は、「一人事業を3/31まで続けられない」ことを意味する。その場合は、ゲーム2を打ち切る判断になるので、オファーを受ける前にこのルールブックの見直し日を前倒しする |
| 今の候補への注意 | 大手コンサル（デロイト、PwC、EY）の残業は推計で月40〜60時間程度。副業は申請制で、EYは規定が厳しいとされる。②の条件と両立するかを、面談で必ず確認する |
| 今の本業でできること | プロマネ的な立場を外れた悔しさは、「腕前とスコアが連動しない」不満とつながっている。今の職場で、自分の数字が明確に見える担当範囲（例：特定ブランド・特定チェーンのオフライン売上）を持てないかを、上司に相談する価値がある。転職より低コストで、本業の惰性を減らせる可能性がある |

## 6. お金：目標の数字と期限の妥当性

### 6-1. 理想の暮らしに必要な資産（概算）
家族の時期（子ども3〜4人）を想定した年間支出の目安：

| 項目 | 年額（概算） |
|---|---|
| 海外旅行（2〜3か月に1回、家族で1週間） | 約500〜750万円 |
| 国内旅行（月1回、2泊3日） | 約200〜300万円 |
| 子どもの教育（4人、私立・海外を含む） | 約350〜450万円（総額1億円前後を約22年で均す） |
| 基本の生活費（御代田の戸建て） | 約500〜600万円 |
| 自由に使えるお金（月30万円） | 約360万円 |
| 犬2頭 | 約50〜60万円 |
| **合計** | **約2,000〜2,500万円／年** |

- 安全に取り崩せる率を3.7〜3.9%とすると（Morningstar, 2025）、必要な資産は約5.1〜6.8億円。
- 一度きりの支出（御代田の戸建て約6,000万〜1億円、親の新居3,000〜5,000万円）を加えると、**約6〜8.3億円**。税金を考えると、本人の「5〜10億円」という感覚は、根拠のある範囲に収まる。
- サイドFIRE（事業で年1,000万円を稼ぎ続ける）なら、取り崩しに必要な資産は約3.2〜3.9億円、一度きりの支出を加えて約4.1〜5.4億円に下がる。

### 6-2. 期限「30歳（2030-09-22）」の妥当性
- 残り約4年で6億円以上を作るには、平均で年1.5億円以上の資産増加が必要。給与（年800万円）と積立投資の組み合わせでは、1桁以上足りない。届く道は、事業の売却か、急成長企業の株式報酬のような、大きな一発に限られる。
- **提案：期限と金額を、行動の軸から外す。** 本人の回答でも、余暇の罪悪感を消すのに必要なのは金額ではなく「軸に取り組んでいること」だった（S4）。10億円は方向を示す北極星として残し、日々の判定は5章のゲームで行う。
- 期限を変えるかどうかは本人の判断。変える場合は、ゲームの判定日（2027-03-31）に行う。判定期間の途中では変えない。

## 8. 未解決の論点

1. **軸の対象：** 11月の助走と、12月からの実験で見つける。
2. **パートナーとの擦り合わせ：** 結婚の時期、子どもの人数、住む場所、旅の頻度。ルールブックは自分だけのものと決めたが、2章の指針の「家族」に関わる部分は、彼女の望む暮らしを知らないまま確定できない。
3. **素のままでいられる相手：** 「わからない」と答えた。同志の条件（出力ゲームをしなくていい関係）に直結するので、ゲームを進めながら観察する。
4. **自己分析の見直し：** 「起業家は適性が低い」という過去の結論（#11）は、ゲーム2の実験結果で検証する。考えて結論を出すより、実験のデータで判断する方が、この人の特性に合っている。

## v0.1からの主な変更点

| 変更 | 理由 |
|---|---|
| ルールを10本から「核3本＋補助6本」に絞った | 仕組みを増やすほど止まるパターンがあるため。ルールブック自体が新しい仕組みになる危険を下げる |
| 診断を因果のつながりとして整理し、反証条件を加えた | 「保険」という解釈が外れていた場合に、別の処方へ切り替えられるようにするため |
| 11月は減量を主役にし、一人事業は助走にした | 同時に走らせるゲームの数を減らすため |
| 減量の実現可能性を数字で見積もった | 目標を下げずに、結果をデータとして扱う準備のため |
| 30歳・10億円の期限が現実的でないことを明記した | 期限が行動の軸になると、届かない数字が罪悪感の源になるため |
| 今の本業で「数字の見える担当範囲」を持つ選択肢を加えた | 転職より低コストで、腕前とスコアの連動を取り戻せる可能性があるため |
